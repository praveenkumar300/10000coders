HTML Lists

A list in HTML is a way to group related items together in a structured format using special tags.

1.Odered List

  • An ordered list displays items with numbers/letters/roman numerals.
  • The <ol> tag is used to create an ordered list.
  • Each item in the list is defined using the <li> tag.

2.Unordered list:

  1. An unordered list displays items with bullets.
  2. For unordered list we use <ul> tag
  3. Each item in the list is defined using the <li> tag.

3.Definition/Description list:

Used for terms and their descriptions.

description List :
A description list in HTML is used to display a list of terms and their corresponding descriptions or definitions. It is particularly useful for presenting name-value pairs, such as a dictionary-style format or questions and answers.
  • <dl> → Tag for creation of Description list
  • <dd> → Tag for Description definition
  • <dt> → Tag for Description term
